# App Store Connect Setup - Complete These Steps

## 🚨 **URGENT: Complete These Required Items**

### **1. Choose a Build**
1. Go to **App Store** tab
2. Click **"Select a build before you submit your app"**
3. Choose: **Version 1.0.0, Build 4** (latest build)

### **2. Age Rating Setup**
1. Go to **App Information** → **Age Ratings**
2. Click **"Set Up Age Ratings"**
3. Answer questions:
   - **Profanity or Crude Humor**: ✅ Yes (jokes)
   - **Alcohol, Tobacco, or Drug Use**: ❌ No
   - **Sexual Content**: ❌ No
   - **Violence**: ❌ No
   - **Gambling**: ❌ No
4. Should result in **4+** rating

### **3. App Privacy Setup**
1. Go to **App Privacy** tab
2. Click **"Get Started"**
3. Add **Privacy Policy URL**: `https://humorous.app/privacy`
4. Answer data collection questions:
   - **Email Address**: ✅ Yes (for account creation)
   - **User ID**: ✅ Yes (for app functionality)
   - **Analytics**: ✅ Yes (for app improvement)
   - **No Tracking**: ✅ Check this box

### **4. Content Rights**
1. Go to **App Information** → **Content Rights**
2. Click **"Set Up Content Rights Information"**
3. Check **"I confirm that I have all rights to use this app"**

### **6. App Icon**
1. Go to **App Information** → **App Icon**
2. Upload: `assets/icon.png` (1024x1024)

## ✅ **After Completing These Steps:**

2. Go to **App Store** tab
3. Click **"Submit for Review"**
