## About

**Humorous** is a simple, swipeable joke generator app built with **Expo (React Native and TypeScript)** and **Supabase**. Users can swipe through joke cards, tap to reveal punchlines, and provide feedback that is stored remotely.

## Features

- Swipeable joke cards (Tinder-style)  
- Tap to reveal punchlines  
- Like or dislike jokes with swipe gestures  
- Feedback saved in Supabase database  
- Works out-of-the-box with mock data for easy testing  

## Technology Stack

- **Frontend:** React Native with Expo, TypeScript  
- **Backend:** Supabase (for storing user feedback)
