## About

**HumorousAdmin** is the companion web application for the Humorous iOS app — a TikTok-style AI-powered joke feed. Built with **Next.js** and **TypeScript**, it provides a public-facing landing page, support resources, and a privacy policy for App Store listing requirements.

## Features

- Landing page for the Humorous iOS app
- Support page with contact information and help resources
- Privacy policy page for App Store compliance
- Fast, server-side rendered pages via Next.js App Router

## Technology Stack

- **Frontend**: Next.js, React, TypeScript
